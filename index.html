Lenguaje de programación

Programá en Rust

Las actividades de Mini Lab están pensadas alrededor de Rust, un lenguaje moderno que permite trabajar con sistemas embebidos priorizando seguridad y rendimiento.

No necesitás experiencia previa en Rust. La plataforma busca acompañarte desde la configuración inicial hasta el trabajo directo con el hardware.

main.rs 
#![no_std]
#![no_main]

use cortex_m_rt::entry;

#[entry]
fn main() -> ! {
    loop {
        // Tu programa embebido
    }
}
