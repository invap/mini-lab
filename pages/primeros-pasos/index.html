01 Entorno de desarrollo

Linux

Mini Lab utiliza Linux nativo como entorno de desarrollo para trabajar con la toolchain de Rust y los dispositivos del kit.

i

Los pasos de esta guía están pensados para realizarse sobre Linux instalado de forma nativa. Otros entornos no forman parte del alcance actual de Mini Lab.

Antes de continuar

  • ✓

  • ✓

  • ✓

Si ya tenés Linux instalado y una terminal disponible, podés avanzar directamente al siguiente paso.

02 Rust embebido

Instalá la toolchain

La toolchain reúne las herramientas de Rust que necesitamos para compilar, generar e inspeccionar programas para sistemas embebidos.

01

Rust y rustup

rustup administra las versiones y componentes de Rust. Al instalar Rust con rustup también obtenemos rustc, el compilador, y Cargo, la herramienta que gestiona proyectos, dependencias y compilaciones.

rustup
Administra toolchains, componentes y targets.
rustc
Compila el código fuente escrito en Rust.
cargo
Gestiona el proyecto, sus dependencias y compilaciones.

En Linux, que es el sistema soportado actualmente por Mini Lab, podés iniciar la instalación con:

Terminal Linux 
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Al terminar, para actualizar la terminal actual ejecutá el siguiente comando, o simplemente cerrá la terminal y abrí otra:

Terminal 
source "$HOME/.cargo/env"
02

Agregar el target de compilación

La Raspberry Pi Pico 2 utiliza el microcontrolador RP2350. En Mini Lab vamos a trabajar inicialmente con sus núcleos ARM Cortex-M33.

Para que Rust pueda generar código para esta arquitectura, agregamos el target correspondiente:

Terminal 
rustup target add thumbv8m.main-none-eabihf
¡

Este target genera código ARMv8-M para Cortex-M33 utilizando soporte de punto flotante por hardware.

03

LLVM Tools y cargo-binutils

Las LLVM Tools permiten inspeccionar los binarios generados por Rust. cargo-binutils agrega comandos de Cargo para utilizar herramientas como size, objdump y nm de una forma más cómoda.

Terminal 
cargo install cargo-binutils --locked
rustup component add llvm-tools-preview
04

cargo-generate

Permite crear un proyecto nuevo a partir de una plantilla ya preparada. Esto evita tener que configurar desde cero los archivos y ajustes que necesita un proyecto bare-metal.

Terminal 
cargo install cargo-generate --locked

El comando instala cargo-generate. Para descargar plantillas vas a necesitar Git, que instalaremos en el paso 3 antes de crear un proyecto.

03 Sistema operativo

Configurá Linux

Con la toolchain de Rust preparada, ahora vamos a instalar las herramientas del sistema que usaremos para ejecutar, depurar y comunicarnos con el hardware.

Sistema actualmente soportado Linux
01

Instalar las herramientas de Linux

Para seguir el recorrido instalaremos Git, un depurador con soporte ARM, OpenOCD y QEMU. Elegí el comando correspondiente a tu distribución.

Ubuntu / Debian APT 
sudo apt install git gdb-multiarch openocd qemu-system-arm
Fedora DNF 
sudo dnf install git gdb openocd qemu-system-arm
Arch Linux Pacman 
sudo pacman -S git arm-none-eabi-gdb qemu-system-arm openocd
02

¿Para qué sirve cada herramienta?

GDB
Depurador que permite detener la ejecución, avanzar paso a paso e inspeccionar el estado del programa. Necesitamos una versión con soporte para ARM Cortex-M.
OpenOCD
Facilita la comunicación entre las herramientas de depuración de la computadora y el hardware embebido mediante un probe compatible.
QEMU
Emula determinados sistemas ARM. No reemplaza automáticamente la placa Pico 2; solo sirve para las prácticas y targets compatibles con la máquina emulada.
03

Acceso al hardware desde Linux

La Raspberry Pi Pico 2 puede recibir firmware directamente mediante su conexión USB utilizando el modo BOOTSEL.

1
Mantené presionado BOOTSEL

Con la placa desconectada, mantené presionado el botón BOOTSEL mientras conectás el cable USB.

2
Linux detecta la Pico 2

La placa aparece como una unidad de almacenamiento llamada RPI-RP2.

3
Copiá el firmware

Copiá el archivo .uf2 a esa unidad para programar la memoria flash.

i

Este mecanismo forma parte de la ROM del RP2350, por lo que el modo BOOTSEL permanece disponible aunque el firmware cargado tenga algún problema.

04 Verificación

Comprobá tu entorno

Antes de crear nuestro primer proyecto, vamos a comprobar que la toolchain de Rust y las herramientas de Linux quedaron instaladas correctamente.

i

Ejecutá cada comando en una terminal. No importa que las versiones mostradas sean exactamente iguales: lo importante en esta etapa es que las herramientas estén disponibles y respondan correctamente.

01

Rust y Cargo

Primero verificamos las herramientas principales instaladas mediante rustup.

✓ Rust
Terminal

✓ Cargo
Terminal

✓ Rustup
Terminal 
rustup --version
02

Target de la Pico 2

Confirmamos que Rust puede compilar para el ARM Cortex-M33 del RP2350.

Terminal 
rustup target list --installed | grep thumbv8m.main-none-eabihf
✓
