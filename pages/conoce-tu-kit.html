Conocé tu kit

Descubre los componentes que vienen incluidos en el kit

Raspberry Pi Pico 2

Placa principal utilizada para desarrollar y ejecutar los programas del kit.

Protoboard

Permite realizar conexiones y prototipos electrónicos sin necesidad de soldar.

MPU6050

Sensor que combina acelerómetro y giroscopio para detectar movimiento.

Cables Dupont macho-macho

Cables utilizados para conectar componentes en protoboard o placas de desarrollo.

LED Rojo

LED de color rojo utilizado para indicación visual en proyectos electrónicos.

Resistencias

Componentes utilizados para limitar el flujo de corriente en los circuitos electrónicos.

Botón Pulsador

Componente utilizado para enviar una señal de entrada a un circuito electrónicos.
