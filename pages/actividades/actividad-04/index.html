03 Entendé

¿Qué es el MPU6050?

El MPU6050 combina un acelerómetro y un giroscopio. Puede medir aceleraciones y movimientos sobre tres ejes.

Aceleración X · Y · Z
+
Rotación X · Y · Z
i

En este primer contacto vamos a trabajar solamente con el acelerómetro. El giroscopio se puede explorar más adelante utilizando el mismo bus I²C.

04 Conectá

Conectá el MPU6050

Agregá el MPU6050 al circuito en Velxio y conectá las líneas del bus I²C.

SDA
GP4 Línea de datos I²C
SCL
GP5 Señal de reloj I²C
+
VCC → 3V3 Alimentación del sensor
−
GND → GND Tierra común
i

Vamos a utilizar I²C0 con GP4 como SDA y GP5 como SCL.

05 Configurá

Configurá el bus I²C

Primero importá las herramientas necesarias para trabajar con I²C.

src/main.rs Imports 
use core::fmt::Write;
use embedded_hal::i2c::I2c;
use rp235x_hal::gpio::{FunctionI2C, Pin};

Después de inicializar los GPIO, configurá los pines y creá el controlador I²C:

src/main.rs I²C0 
let sda_pin: Pin<_, FunctionI2C, _> =
    pins.gpio4.reconfigure();

let scl_pin: Pin<_, FunctionI2C, _> =
    pins.gpio5.reconfigure();

let mut i2c = hal::I2C::i2c0(
    pac.I2C0,
    sda_pin,
    scl_pin,
    400.kHz(),
    &mut pac.RESETS,
    &clocks.system_clock,
);
i

El bus está configurado a 400 kHz. Varios dispositivos pueden compartir SDA y SCL porque cada uno tiene su propia dirección.

06 Identificá

Comprobá que el sensor responde

El MPU6050 utiliza normalmente la dirección I²C 0x68. Podemos consultar su registro de identificación para verificar la comunicación.

Dirección I²C 0x68
→
WHO_AM_I 0x75
src/main.rs WHO_AM_I 
const MPU6050_ADDR: u8 = 0x68;

let mut who_am_i = [0u8; 1];

i2c.write_read(
    MPU6050_ADDR,
    &[0x75],
    &mut who_am_i,
).unwrap();

writeln!(
    uart0,
    "WHO_AM_I: 0x{:02X}",
    who_am_i[0]
).unwrap();
Resultado esperado

Si la comunicación funciona correctamente, el Serial Monitor debería mostrar WHO_AM_I: 0x68.

07 Inicializá

Activá el MPU6050

Al iniciar, el MPU6050 se encuentra en modo de bajo consumo. Para comenzar a medir debemos escribir en su registro de administración de energía.

src/main.rs PWR_MGMT_1 
i2c.write(
    MPU6050_ADDR,
    &[0x6B, 0x00],
).unwrap();
i

0x6B corresponde al registro PWR_MGMT_1. Escribir 0x00 permite que el sensor comience a funcionar normalmente.

08 Leé

Leé la aceleración

Los datos del acelerómetro comienzan en el registro 0x3B. Vamos a leer seis bytes: dos para cada eje.

src/main.rs Acelerómetro 
let mut accel_data = [0u8; 6];

i2c.write_read(
    MPU6050_ADDR,
    &[0x3B],
    &mut accel_data,
).unwrap();

let accel_x = i16::from_be_bytes([
    accel_data[0],
    accel_data[1],
]);

let accel_y = i16::from_be_bytes([
    accel_data[2],
    accel_data[3],
]);

let accel_z = i16::from_be_bytes([
    accel_data[4],
    accel_data[5],
]);
i

Cada medición ocupa dos bytes. Por eso usamos i16::from_be_bytes() para reconstruir cada valor de 16 bits.

09 Observá

Mostrá los datos por UART

Reutilizá la comunicación serial del Tutorial 1 para observar las lecturas del sensor.

src/main.rs Serial Monitor 
writeln!(
    uart0,
    "X: {} | Y: {} | Z: {}",
    accel_x,
    accel_y,
    accel_z,
).unwrap();

Juntando la lectura dentro del loop principal:

src/main.rs Loop 
loop {
    let mut accel_data = [0u8; 6];

    i2c.write_read(
        MPU6050_ADDR,
        &[0x3B],
        &mut accel_data,
    ).unwrap();

    let accel_x = i16::from_be_bytes([
        accel_data[0],
        accel_data[1],
    ]);

    let accel_y = i16::from_be_bytes([
        accel_data[2],
        accel_data[3],
    ]);

    let accel_z = i16::from_be_bytes([
        accel_data[4],
        accel_data[5],
    ]);

    writeln!(
        uart0,
        "X: {} | Y: {} | Z: {}",
        accel_x,
        accel_y,
        accel_z,
    ).unwrap();

    delay.delay_ms(500);
}
