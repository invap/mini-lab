Tutorial 03 · Nivel inicial

Controlá un LED con un botón

Aprendé a leer una entrada digital desde Rust. Vas a conectar un botón al microcontrolador y usar su estado para controlar el LED.

Qué vas a aprender

Hasta ahora usamos GPIO como salida. En este tutorial vamos a utilizar un pin como entrada y tomar decisiones según su estado.

Vamos a usar la resistencia pull-up interna del microcontrolador. Por eso no necesitamos agregar una resistencia externa al botón.

04 Entendé

¿Qué hace el pull-up?

Cuando el botón está abierto, el pull-up mantiene GPIO14 en HIGH. Al presionarlo, el pin queda conectado a GND y pasa a LOW.

05 Programá

Configurá GPIO14 como entrada

Después de inicializar los pines, agregá la configuración del botón.

src/main.rs GPIO Input 
let button = pins.gpio14.into_pull_up_input();
i

into_pull_up_input() configura GPIO14 como entrada y activa su pull-up interno.

06 Experimentá

Controlá el LED con el botón

Reemplazá el loop del Tutorial 2 por una condición que compruebe constantemente el estado del botón.

src/main.rs Loop 
loop {
    if button.is_low().unwrap() {
        led_pin.set_high().unwrap();
    } else {
        led_pin.set_low().unwrap();
    }
}
Resultado esperado

Mientras mantengas presionado el botón, el LED debería permanecer encendido. Al soltarlo, debería apagarse.

★

Desafío final

Invertí el comportamiento

Modificá el programa para que el LED esté encendido cuando el botón está suelto y se apague mientras lo presionás.

  • No cambies el circuito.
  • Modificá solamente la lógica del programa.
  • Predecí el resultado antes de ejecutarlo.
  • Probalo nuevamente en Velxio.
